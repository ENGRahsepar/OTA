# OTA — xaga (POCO X4 GT) · Infinity X 17

Updater JSON for the **Infinity X 4.1** ROM on xaga (POCO X4 GT).

Updater URL in ROM: `https://raw.githubusercontent.com/ENGRahsepar/OTA/17/xaga.json`

- Branch `17` holds `xaga.json`
- Upload ROM zip to SourceForge, then generate json:
  `python3 ~/xaga/ota_xaga.py <rom.zip> https://sourceforge.net/projects/YOUR-SF-PROJECT/files/xaga/17/gapps 4.1`
- Push updated `xaga.json` to branch 17.
